About

Engineering the server side, end to end

I'm a backend-focused full-stack developer at PixelCode Technologies. My work starts at the data model — schemas, migrations, authentication and API design — and carries through to the interfaces that use them.

Most of my server-side experience is in Python with Django and Django REST Framework: token-based authentication, CRUD services and automated inventory logic, backed by MySQL. I also build with PHP and Laravel, use Node.js for server-side JavaScript, and turn back ends into finished applications with HTML, CSS, Bootstrap and JavaScript. I care about clean data design, sensible endpoints and code a teammate can actually maintain — and I'm working toward deeper backend and distributed-systems expertise.
